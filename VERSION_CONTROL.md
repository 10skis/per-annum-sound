# Per Annum Sound: Version Control

**Status:** Active
**Started:** 2026-11-02
**Location:** This folder. Scope in [SCOPE.md](SCOPE.md), code in [app/](app/README.md).
**Goal:** A DIY Raspberry Pi radio for NTS and other internet radio on the Edifier speakers, with physical controls and an iPhone/Mac web app as a second remote. Personal project.

## Current version
v0.20: Per Annum Sound web app with 53 stations, console styling, nav map, halftone art, schedule, spectrum and on-device playback, plus a no-server build for a free static host so it works away from home before the Pi, live at https://spiffy-elf-9ebf5d.netlify.app. Radio output still on a mock player until MPD is installed. Hardware not ordered
