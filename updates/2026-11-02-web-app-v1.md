# v0.2: Web app first build

**Date:** 2026-11-02
**Project:** Pi Radio

## What changed
- Built the control service (`app/server.py`) and web app (`app/static/index.html`). Tested at phone size in the browser on a mock player: NTS keys, play switch, dial (drag to step, tap to play/stop, arrow keys), volume, station list, live show info, amber dithered art and a scrolling text strip.
- `stations.yaml` holds 29 stations: NTS 1 and 2, all 16 Infinite Mixtapes, and 11 others, each stream checked.
- Added an MPD config for hearing it on the Mac (`app/dev/mpd.conf`), a home-screen icon and a README.

## Why
- Robert chose to build the app before the hardware. It runs on the Mac now and moves to the Pi unchanged.

## Decisions made
- Build order changed: web app first, physical device after.
- Swappable player: MPD when it's reachable, otherwise a silent mock, so the app can be built without audio.
- Both scope assumptions about NTS hold: all mixtapes have public stream URLs, and the live feed includes show art.
- SomaFM left out for now: its streams didn't respond from here.
- Web app look: amber on dark, cream keycaps, knurled dial, toggle lever, VT323 dot-matrix type on the screens.
