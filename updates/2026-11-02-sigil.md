# v0.30: Sigil art for stations without artwork

**Date:** 2026-11-02
**Project:** Per Annum Sound

## What changed
- Stations with no artwork now show a **sigil** instead of their name cut out of a halftone: eleven rings of dotted grooves like a record, each ring's arcs switched on or off by the station's name so every station has its own mark, with unlit dots faintly visible. The station number sits in the middle with its city code underneath (matching the dial and map). The shimmer and ripple run across it like real cover art.
- Same design in the browser and in `art.py` for the server (which uses the first three letters of the city for the code). The old name-fitting code is removed.

## Verified
- Christmas Vinyl HD shows its sigil with 41 / NPL in the browser version; the server version renders the same layout.
