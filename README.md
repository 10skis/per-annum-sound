# Per Annum Sound

An internet radio for NTS, Infinite Mixtapes and about 80 stations from around the world, with a retro dot-matrix console, a station map, halftone art and a live spectrum. It runs as a web app now and will run on a Raspberry Pi with amber OLEDs and physical controls later.

Live at https://10skis.github.io/per-annum-sound/
