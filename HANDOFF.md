## How it runs

| Thing | How |
|---|---|
| Server version (the Pi later) | `app/run.sh`, port 8080. FastAPI plus MPD; falls back to a silent mock player when MPD isn't running |
| No-server version (GitHub Pages) | `.venv/bin/python build_static.py` writes `app/web/`. Serve locally with `python3 -m http.server 8090` from `app/web` |
| One page, two modes | `app/static/index.html` serves both. The build injects `window.PI_RADIO_STATIC = true`; the `DATA` object switches between the server API and fetching NTS and stations.json directly |
| Station data | `app/stations.yaml`: groups, `places` (lat/lon/label), `timezones`, per-station `about`, `info`, `genre`, `glyph`, `profile`, `founded`, `notable`, `site`, `map`, plus `codes` (airport-style city codes for the map and sigil; London is LDN by choice, not LON). Loaded by `catalog.py` for both server and build, which sorts each group by place A to Z, then name, with Online last; that is the list and dial order, so file order within a group doesn't matter |
| Art | `art.py`: 45° halftone for covers, 1-bit for logos, sigil for stations with none. The page has matching JS for the no-server build |
| Map land | `make_map.py` builds `static/worldmap.js` from Natural Earth (`dev/ne_110m_land.geojson`) |
| Offline | `static/sw.js`, copied to the web root by the build |
| App icon | Glyph dial: the rotating-window arc of katakana with the lit ｦ shown large in LED dots, dark dot-matrix plate, glass highlight, no letters (iOS 26/27 style; the sigil and display-window versions were rejected). Drawn by the page (`dev/icon.js`); `make_icons.py` serves web/ and saves what the page posts. Steps in its docstring |

After any change: rebuild `web/`, check in the browser at 1371 or 1440 px and at 375 px, then log (update file, VERSION_CONTROL, PROJECTS, TODO) and push.

## Design rules (Robert's decisions; don't undo)

| Area | Rule |
|---|---|
| Colour | Amber is the default accent in every display mode; since v0.95 a COLOUR strip in the display panel turns it to phosphor green (Robert's call; amber to green only, no other hues). The warning blue never turns. Eclipse GREEN with green lettering is low contrast: Robert chose to allow it and avoid it himself. The original tokens: The original tokens: `--amber #ffb02e`, `--amber-mid #d08c26`, `--amber-dim #9c6c22`, `--amber-ghost #241907`, `--line #4a3616`. Blue `#4fb4ff` for warnings only (no signal, offline, sleep's last minute). Map city dots yellow `#e8c43a` (hot `#ffe56e`). Nothing else |
| Type | VT323 for data, Saira Condensed for labels, Michroma for the brand only |
| Look | "Cyberpunk alien car dashboard", leaning retro-analog: chamfered panels, no panel name tabs (removed in v0.77 per `context/visual-design.md`; Robert also dropped the Signal panel's Day & night and listening headings in v0.74), registration brackets, unlit 88 behind numerals, dot matrix everywhere. Robert reacts badly to over-literal brand references (Braun etc.) |
| Dial (desktop) | No glyphs that read as a known symbol (⌘ was swapped out). A station can set `glyph:` for a drawn one from `GLYPH_ART` (Christmas Vinyl HD has a tree); drawn glyphs use currentColor, never emoji, and are absolutely centred in the slot (inline SVG sits on the baseline and rides high). Text glyphs go through `glyphFor()`, which wraps each in a `.gc` span nudged by `glyphNudge()` (ink measured on a canvas) so it centres; slots centre with flex, since text-align can't centre a glyph wider than its box. Rotating window: ring of katakana glyphs, about six either side of the current one, fading. Not the centerpiece (he rejected that mockup). ◀ turns the ring clockwise, ▶ anticlockwise; drag follows the hand; scroll down or right = next |
| Tape tuner | Under the dial (desktop) and under the tuner (phones). Thin 1 px analog ticks, a number every fifth, group bands, needle. Swipe or drag left = higher stations |
| Volume | Two-finger swipe right = louder |
| Phones | Tuner strip instead of the dial; no clock in the header (status bar has it); ? in the header; brand shows P·A·S |
| Level displays | Eight: Trace, Meter, Needle, Goniometer, Loudness, then eye candy (Phosphor, Fluid, Reels). Goniometer is the first version, a random dot cloud with LO and HI clouds; v0.49's trace lives on as Phosphor. Eye candy is welcome here; avoid repeating the spectrum screens' displays. Fluid is a 3D dot surface with spikes; Phosphor, Goniometer and Fluid all have LO and HI side versions |
| Art shimmer | Breathing, not flashing (v0.50): a 5.2 s ring or 4.6 s sweep every 7 to 16 s, dots swelling by up to about 40%, no highlight colour. Cover art and sigils (v0.51). Since v0.49 halftone art swells its own dots (read back from the image onto `#artDots`, image hidden only during the ripple); logos keep the `.shimmer` overlay |
| Hold | Tap the art to hold shimmer and sigil rotation; tap the title to stop its scroll. Tap again resumes; remembered per device. About opens from the line under the title and the description, not the title |
| Sigil (no artwork) | Turning dotted rings, city code large with city name under it (not the station number), glowing dot matrix behind (a halo under each dot, v0.65; page and art.py match). Breathes with the same ripple as cover art |
| Map | Dots only; label wipes out on hover. World view drifts left slowly, pauses on hover. Click empty map = zoom 1.9×, again = out; drag or scroll pans. USA and EUROPE carry borders and state/province lines (both dashed amber, so the two ranges match), rivers and lakes from `static/geo.js` (`make_geo.py`, Natural Earth 1:50m), drawn once into the cached base layer. Phones (map under 460 px) get none of it, plain dots like TERRA (Robert's call). Ranges USA, EUROPE, TERRA (the world view; `world` in code and storage) and GALAXY; in TERRA, tapping the European or North American cluster zooms to that range. GALAXY (`drawGalaxy`) is the collection as a barred spiral: NTS round the bulge, one arm per group lit by group size, stations along it by longitude; a halftone on a fixed grid from a polar light table, about 1 ms a frame. Since v0.92 it's drawn in the maps' fixed palette like Terra: square dots up to Terra's 3 px #86601f land, yellow `MARK` station squares, dotted arm lines, #9c6c22 plotter text, a dotted graticule outside the disc, no orbit rings. It used to read the CSS tokens, which are already bright and went white under Lunar's canvas filter; canvas art should use the maps' fixed colours. Tap a star to play; tap empty space to zoom 2.6× (the grid stays put and the disc grows under it), drag or scroll to move, tap again to come out. Zoom and pan share `zoomStep`/`toggleZoom` with the maps |
| Signal panel | Every station gets: what's on (NTS timeline or recent tracks), day and night bar, nearby and similar, your listening |
| Board | Search at the end of the Recently played row (its own row on phones, v0.82): every word must match a station's name, city, place, code, genre, group, "NTS" for any NTS channel, or the row's live subtitle. Matching groups open for the search without touching the saved open state; empty groups hide; Enter plays the first match; / focuses, Esc clears. Collapsible groups. Columns: NTS Live and Infinite Mixtapes; Terrascan FM and Genre Radio; Deep Cuts and Talk Radio (`GROUP_COL`). Two columns 960–1279 px (third column under the second), three from 1280. Recently played ticker above the columns, hover lights the row |
| Header readouts | City, position, local time, distance from NYC, signal. Scroll slower than the station title when too long |
| Motion | Smooth easing (cubic-bezier(.3,.7,.3,1)), not stepped. Everything off with reduced motion |

## Traps already hit

| Trap | What to do |
|---|---|
| Canvases inflating the layout | A canvas with height 100% in a grid or flex row feeds its own size back. Use `contain: size` on the canvas, and on `.artcol` and `.strip`, so the right-hand controls set the top row's height |
| Boot animation | `.unit > *` runs the stepped boot flicker, and an animation restarts whenever an element goes from `hidden` to shown. Anything that toggles inside `.unit` (the display panel) needs `animation: none` (v0.80). Its fill mode also holds a direct child's opacity at 1, so an opacity rule on a direct child of `.unit` (like `.vol`) does nothing: target its children (v0.89) |
| Colour setting | `DISPLAY` turns the accent tokens (`ACCENT`: amber, mid, dim, ghosts, line, glows, textures) toward OKLCH hue 145 by the setting's fraction, only where a colour is amber-like (hue 30-110, chroma over .03), so chassis tints, cream lettering and Solar's slate don't move. Canvases and art get `hue-rotate(var(--hue-rot))` at the end of every mode's filter: 70 deg for Lunar and Eclipse (#ffb02e to #4fe245), 90 for Solar's dark ink (#9f3b00 to #006b00). Stored as piRadioHue (0-1), snapping to the ends within .1. Hard-coded CSS ambers must become tokens or they won't turn (the day bar was fixed in v0.95) |
| Panel textures | Three, kept distinct on purpose (v0.86-0.90): the controls plate has 7 px dots (`--plate-dot`), the now-playing panel and the desktop station list 14 px fainter dots (`--strip-dot`, on `::before` so the chamfer diagonals survive; the list since v0.94), the Level and spectrum panels a 12 px grid (`--grid`, on their canvases; v0.91 added spectrum). All are `DISPLAY` tokens |
| Power off | Stopped, `.unit.idle` (set with the art's and title's `.off`) dims the map canvas and foot, the Level and spectrum displays, presets, shuffle, PLAY/STOP (since v0.98, by its two halves; while stopped PLAY breathes 25% to 45% every 4 s with a faint halo, the `standby` keyframes, since v0.101), dial, tape, VOL and the phone tuner to 25%; everything stays usable (v0.89). Since v0.96 one pair of CSS transitions covers those and the art and title together: down .5 s, fast then settling; up 1 s, slow start, sweeping controls, then title (+.1 s), art (+.2 s), map (+.3 s). Robert read v0.93's stepped flicker as a glitch, not a power-up: keep power changes smooth. The delay rules need id selectors to outweigh the base rule. The Level and spectrum displays dim and warm up exactly like the map since v0.100 (v0.99 left them lit when stopped with a separate warm-up, which Robert found incongruent). Since v0.97 PLAY/STOP's amber also moves between the halves on the same curves (PLAY 1 s warm-up, STOP .5 s fall); a press still answers in .08 s |
| Class name clashes | It's one 2,500-line file. The ticker once used `.tk`, the tape's tick class, and turned the ticks into a solid line. Grep a class name before using it |
| Phone header | The full header needs about 460 px, so below 960 px (where the unit is at most 420 wide) it shows P·A·S and drops the clock and "ON AIR". Anything wider than the screen widens the whole page on iPhone and knocks the art and tape out of line |
| Off-air stations | The Lot Radio (`lot`) goes off air at times; its playlist then answers #EXT-X-ERROR and the page shows NO SIGNAL under the title. Check their site before calling a stream dead |
| Storage | `store` is defined in the `<head>` script with `DISPLAY` (v0.88) and shared by the page; don't redeclare it in the body script, since a second `const store` is a SyntaxError that stops the whole page |
| Testing | `dev/check_streams.py` (data and every stream, server-side) and `dev/selftest.js` (run in the page: `selfTest.core()`, `play(from, to)` in slices of 11, `layout()` per width). Neither is shipped in `web/` |
| Visual guidelines | `context/visual-design.md` applies, with this project's look as the agreed exception for the console, displays, halftone, dot font and caps. Still avoid: section numbers, non-interactive pills, extra dividers, and see-through colours that aren't one of the CSS tokens (`--glow`, `--glow-soft`, `--warn-glow`, `--texture`, `--vignette`, `--scanline`, `--scrim`) |
| Display modes | LUNAR, ECLIPSE, SOLAR (v0.79; chosen from `mockups/light-modes.html`, replacing night, dusk and bright). LUNAR is the old BRT on pure black. ECLIPSE is a painted chassis with cream lettering and amber accents; its tint is a slider with five notches (grey, green, blue, violet, red, in hue order) that snaps within 0.1 and blends in OKLab between them. Orange and yellow were tried and dropped: amber sank into them. SOLAR is Solarized light: the canvases still draw amber on dark and a CSS filter (brightness, invert, hue-rotate 180°) turns them to ink on pale glass, so `--screen` stays dark in Solar. One brightness setting (40-140) moves the lettering and line tokens and `--lum` on the displays and art, never backgrounds. All of it lives in `DISPLAY` in `<head>`, which writes every colour inline on `<html>` before first paint; CSS holds only each mode's filters and overlays. Since v0.83 every mode has a tint strip: Lunar BLACK / GRAPHITE / GREY (v0.84, black to grey at Robert's ask; GREY #3d3d3d is the lightest that keeps the quiet amber lettering over 4.5:1, so it can't go to light grey) and Solar COOL / CREAM / WARM move only the chassis, glass, lines and unlit segments. Lunar defaults to BLACK, Solar to CREAM. Solar's painted glass is `--glass`; its canvas ink stays the same in every notch (the filter's contrast takes the canvas glass to near white anyway). Stored as piRadioTheme, piRadioTints (one per mode; v0.79-0.82's piRadioTint becomes Eclipse's), piRadioLum; old night/dusk/bright land on Lunar. The header key (LUN/ECL/SOL) opens the panel under it; T cycles modes, [ ] step brightness, Esc or a tap outside closes. A merged dark-to-light slider was considered and rejected: lettering and the Solar inversion can't blend through the middle. New colours should be `DISPLAY` tokens (canvas code reads them with `cssVar()`), or they'll ignore the mode. The map base layer's cache key includes `--screen` so it redraws when the tint moves. Set only `background-color` on chamfered elements: the `background` shorthand wipes the corner diagonals (the v0.72 DSK bug) |
| Smooth motion | Don't slide dot rows by fractions of a pixel: 2 px dots shimmer as they cross pixel lines (Ridges in v0.59). Keep rows fixed and blend values, and round positions. Measure jitter as the share of pixels changing per frame |
| Dial caret | A `clip-path` triangle, not a CSS border triangle: borders round to whole device pixels and at the desktop fit zoom left it about 1 px off the glyphs (v0.76). `--ring` keeps the lit glyph clear of it. SVG glyphs (the tree) get even pixel sizes (12, lit 16) so centring them never lands on a half pixel, which the browser snaps off-centre |
| Solid controls | Since v0.85 (option A in `mockups/control-weight.html`) the displays' glass sits 35% of the way toward the chassis (done in `DISPLAY.palette`, so canvases that read `--screen` match), and keys, presets, PLAY/STOP, switches, the dial, the readout, the search field and the desktop board are filled with it (`--fill`). Robert's read: outlines on the bare chassis looked hollow next to the filled panels. Since v0.86 a borderless, chamfered plate (`.ctl-plate`, desktop only) sits behind the controls column: `--fill`, the art panel's glass (v0.87; v0.86's lighter halfway tone read as lighter than the panels), with the art's dot matrix in it (`--plate-dot`, 7 px pitch). It's placed on the controls' named grid areas (`out-start` to `vol-end`, v0.88), so its top and bottom line up with the art, Level and signal panels; the controls are raised over it and inset 12 px (Output's top margin, VOL's bottom margin, taken from the dial's padding so the row height and the 89% fit don't change). No frame round it: Robert didn't want a box like the panels. New controls get `--fill` too; lit ones keep amber |
| Key corners | Keys are cut top-left and bottom-right, except shuffle and ◀ (`.key.mirror`: top-right and bottom-left) so their notch faces the key beside them, and the 01/79 readout (`.top-cut`: both top corners) so the tuner row is symmetrical. Two-way switches (`.seg`) are cut like PLAY/STOP, one key in two halves. Robert's choices, v0.63-64 and v0.69 |
| Presets | Twelve in one row: six show, swipe or scroll for 7-12 (snaps by six). Two rows were tried and rejected: too tall for a laptop screen |
| Panel height | Everything on desktop scales with width: shrinking the console widens its layout, and the square art and 2.4:1 map grow taller with it. Adding height to the top row (40 px tried for the Level panel in v0.81, `mockups/level-height.html`) cut the scale from 95% to 89% for 12 px on screen, and Robert couldn't see the gain, so v0.81 dropped it; in v0.84 he chose B after all, as Fluid still looked squished. It's in: `.dial-wrap` has 20 px top and bottom on desktop. Real height has to come from the map's proportions, with every range re-fitted so it doesn't stretch |
| Desktop fit | `fitDesktop()` scales `.note`, `.unit` and `.list` with CSS zoom (floor 70%) until the console fits the window height. Pointer code measuring distances must divide by `scaleOf(el)` |
| Level on phones | Shares Spectrum's spot in `#swipe`: native scroll-snap, dots under it. `placeLevel()` moves the panel there below 960 px and back under the art above. Robert chose this over a separate panel |
| Spectrum screens (03) | New displays go at the end of `VIS_MODES`: the saved choice is an index |
| Canvas glass | Where a display cuts through what it drew (lakes and rivers, map label backings, NO CARRIER, the spectrogram's label column, Ridges' hidden lines) it erases with `knock()` or `clearRect`, never paints `--screen`: Solar's filter turned painted glass near white (v0.88). The map base layer's cache key no longer needs the theme |
| Brightness and glows | `--glow` and `--glow-soft` fade with brightness below 100 (their alpha times the setting, v0.88), or the halos outshine dimmed lettering |
| iPhone status bar | The installed app uses black-translucent (white status-bar text over the page). In Solar a `--status-bar` strip (#073642) fills the safe area at the top in standalone mode only. Untested on a real iPhone as of v0.88 |
| Layering | The art image's drop-shadow filter paints it as its own layer. Anything meant to sit on top (`.shimmer`) needs a z-index, or it's hidden. The shimmer was invisible from v0.17 to v0.33 because of this |
| `hidden` ignored | `[hidden] { display: none !important }` exists because class display rules override the attribute |
| Patching | Edits are scripted string replacements with `assert count == 1`. Comment markers often appear twice (CSS and JS); match the longer, unique form |
| Streams | Must be HTTPS (the Pages site). HLS is only detected by `.m3u8` in the URL; a playlist at a bare address (wyep.org/stream) fails, so use a direct MP3/AAC stream. More than 70 stations needs more `DIAL_GLYPHS`. BBC Radio 4 is UK-only; World Service plays abroad. Track info only from feeds that allow browser access (KEXP, Airtime, radio.co, Radiocult). Kiosk, alHara and FIP logos block browsers, so the build pre-renders them. No "tap play" note: fast scrolling aborts plays and used to flash it. The browser pane runs no animation frames while hidden, so rAF-timed checks stall; test logic directly, or draw frames by hand and save them. `build_static.py` replaces `web/`, so restart any server running from it |
| Wikimedia art | Needs a descriptive user agent (`UA` in `art.py`) or it returns 429 and the build quietly drops the FIP logos. Check `web/art/` after a build |
| Track titles | Some feeds send file names (250119_0258). `fileLike()` in the page filters them; prefer a feed's show name over its track title |
| iPhone | Pages can't set volume; the bar becomes a "use the volume buttons" note |
| Testing in the built-in browser | It won't register service workers; screenshots right after load can be stale or mid boot animation; a hidden pane pauses requestAnimationFrame. For visuals, freeze animations and look at the frame. "Animation running" is not "visible" |
